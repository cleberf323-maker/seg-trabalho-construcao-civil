# Critérios para aceitar uma fonte
Preferência:
1. legislação/norma oficial;
2. bases e órgãos públicos;
3. instituições técnicas reconhecidas;
4. artigo acadêmico;
5. entidades setoriais;
6. matérias jornalísticas/institucionais apenas como complemento.

Para números importantes, buscar a **fonte primária** sempre que possível.
